## 1. Figuras de linguagem

São recursos expressivos que alteram o sentido literal das palavras.

| Figura | O que faz | Exemplo |
|---|---|---|
| Metáfora | Comparação implícita | “Meu coração é um deserto.” |
| Comparação | Comparação explícita | “Meu coração é como um deserto.” |
| Metonímia | Troca por proximidade | “Li Machado” (a obra de Machado) |
| Sinestesia | Mistura de sentidos | “Voz aveludada” |
| Hipérbole | Exagero | “Chorei rios de lágrimas.” |
| Eufemismo | Suaviza | “Ele partiu” (morreu) |
| Ironia | Diz o contrário | “Que ótima ideia” (para algo ruim) |
| Antítese | Ideias opostas | “É um doce amargo.” |
| Paradoxo | Contradição lógica | “O silêncio ensurdecedor.” |
| Personificação | Atribui humanidade | “O vento sussurrava.” |
| Anáfora | Repetição no início | “Eu luto, eu grito, eu resisto.” |
| Pleonasmo | Redundância | “Subir para cima.” |
| Catacrese | Nome emprestado por falta de termo | “Pé da mesa.” |

### Como o ENEM cobra

Normalmente pede o **efeito de sentido**: por que o autor usou aquela figura? A resposta não é apenas “é uma metáfora”, mas o que ela acrescenta ao texto (intensificar, suavizar, criticar, criar humor).

## 2. Funções da linguagem

| Função | Foco | Exemplo |
|---|---|---|
| Referencial | Informação | “A temperatura subiu 2 °C.” |
| Emotiva | Emissor | “Que tristeza!” |
| Conativa | Interlocutor | “Compre agora!” |
| Fática | Canal | “Alô? Está me ouvindo?” |
| Metalinguística | A própria linguagem | “Esta frase tem sete palavras.” |
| Poética | Forma da mensagem | “A lua, musa da noite.” |

Uma mensagem pode ter mais de uma função, mas geralmente há uma **predominante**. Propaganda tende à conativa; notícia, à referencial; poema, à poética.

## 3. Figuras e argumentação

As figuras não são apenas enfeite. Em textos argumentativos, elas podem:

- reforçar uma crítica (ironia);
- criar identificação (metáfora);
- suavizar uma denúncia (eufemismo);
- chamar atenção para um contraste (antítese).

## 4. Pegadinhas

1. Confundir metáfora com comparação (a presença de “como” indica comparação).
2. Achar que metonímia é metáfora (metonímia troca por relação, não por semelhança).
3. Dizer que ironia é “mentira” (é um efeito de sentido).
4. Trocar conativa com emotiva (conativa fala com o outro; emotiva expressa o eu).
5. Ignorar o contexto ao classificar a figura.

## Resumo

- Metáfora compara sem “como”; comparação usa “como”.
- Metonímia substitui por proximidade.
- Funções: referencial, emotiva, conativa, fática, metalinguística, poética.
- Sempre pergunte qual é o **efeito** da figura no texto.
